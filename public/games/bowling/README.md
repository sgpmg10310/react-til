# 🎳 볼링 조추첨 프로그램

농협 볼링 이벤트를 위한 팀 조추첨, 레인 배정, 점수 계산, 보너스 게임 통합 웹앱

---

## 📁 파일 구조

```
index.html          메인 앱 (조추첨 + 점수 입력 + 최종 결과)
battle.html         배틀 전투 게임 (미니게임)
claw.html           인형뽑기 시뮬레이션 게임
css/style.css       메인 스타일
css/battle.css      배틀 게임 전용 스타일
js/app.js           메인 앱 로직
js/effects.js       이펙트 유틸
images/             이미지 리소스
README.md           프로젝트 설명
lunchgame.md        점심 게임 규칙 문서
SKILL.md            프로젝트 스킬/가이드 문서
RULES.md            게임 규칙 및 점수 체계
HOOKS.md            함수 훅 및 연동 포인트
```

## ✅ 구현 완료 기능

### index.html (메인 앱)
| 슬라이드 | 내용 |
|---|---|
| 0 | 설정 화면: 팀 수(3~4), 레인 수(4~8), 팀원 수(2~20), 이름/고수/초보 입력 |
| 1 | 오프닝 애니메이션 |
| 2 | 3·2·1 카운트다운 |
| 3 | 드럼롤 추첨 (수동/자동) |
| 4 | 실력 균형 배분 |
| 5 | 배분 결과 확인 |
| 6 | 최종 팀 확정 |
| 7 | 레인 배치표 (짝 레인 VS 대결) |
| 8 | 1게임 대진표 |
| 9 | 경기 규칙 + **🧸 인형뽑기 시뮬레이션 시작 버튼** |
| 10 | 점수 입력 (1게임/2게임) + 보너스 게임 (인형뽑기 + 10초 맞추기 중복 선택 가능) |
| 11 | 2게임 재대진 |
| 12 | 최종 시상 (불꽃 + 배경음악) |

### battle.html (배틀 전투 게임)
- 팀원 캐릭터들이 아레나에서 자동/수동 전투
- 농협(NH) 로고 건물 벽 표시
- 픽셀 기반 충돌 분리로 캐릭터 겹침 방지
- 도주 시 넘어짐(trip) 애니메이션
- 이름 레이블 가독성 개선

### claw.html (인형뽑기 시뮬레이션) — v3.1
- index.html 슬라이드9(경기 규칙)에서 **바로가기 버튼** 클릭으로 진입
- index.html 슬라이드10(점수 입력) 인형뽑기 패널에서도 **시뮬레이션 버튼** 제공
- `localStorage('clawGameData')`로 팀 데이터 전달
- 팀원 **순환 순서**(A1→B1→C1→D1→A2→B2…) 로 한 명씩 **1회 기회** 진행
- 3D 원근 투영: `project(wx, wz)` → `{sx, sy, sc}`
- 가로 레일(X축) + 세로 레일(Z축 depth) + 수직 지지 기둥 3D 표현
- 집게 상태 머신: `idle → dropping → gripping → rising / rising_empty → to_exit / done_fail → done_success`
- **Bug fix (v3.1)**: 인형 중복 렌더링 완전 해결 (heldDoll 분리)
- **Bug fix (v3.1)**: 잡힌 인형이 갑자기 이동하는 버그 해결 (gripping/rising 중 좌표 동기화)
- **Bug fix (v3.1)**: 없는 위치에 집게 동작하던 버그 해결 (wz 강제 보정 제거)
- 팀별 뽑은 인형 수 집계 → 결과를 `localStorage('clawResult')`에 저장
- 결과 화면에서 볼링 앱으로 돌아가면 인형뽑기 입력란에 **자동 반영**

## 💾 데이터 흐름 (localStorage)

```
index.html (팀 구성 완료)
  ──[launchClawGame()]──▶ localStorage.clawGameData
                              ↓
                         claw.html (게임 진행)
                              ↓
                         localStorage.clawResult
                              ↓
  index.html (buildScoreTables) ──[autoFillClawResult()]──▶ 인형 수 자동 입력
```

### clawGameData 구조
```json
{
  "teams": [
    { "name": "A조", "color": "#FF6B6B", "emoji": "🔴", "members": ["이름1","이름2",...] }
  ]
}
```

### clawResult 구조
```json
[
  { "teamIdx": 0, "teamName": "A조", "caught": 3, "bonus": 40 }
]
```

## ⚙️ 점수 산정 규칙

- 볼링: 레인별 팀원 합산 → 전 레인 합계
- 팀 인원이 5명 또는 홀수인 경우: `(합산 ÷ 팀원 수) × 상대 팀원 수` 로 보정
- 보너스 게임 모두 선택 시 두 게임 점수 합산
