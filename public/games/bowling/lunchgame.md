# 배틀 게임 (3등 이상 외식상품권 수령)

## 게임 특징
재미있는 게임 배경음악이 나오게 해주세요

## 게임 기획
- 참여자 : 윤기수, 박명근, 백용, 배다영, 이동희, 고인수, 지동근, 신기원, 문다훈, 조인혁, 한수빈, 서지훈, 조상현, 김민호, 이기원, 이희수, 오승진, 김남주, 이규빈, 이찬민
- 해당 참여자는 하나의 가상 얼굴을 가진다, 마인크래프트 처럼 조그맣고 귀여운 캐릭터를 가지며, 이름은 하단에 보인다. 
- 시작 버튼을 누르면 각각 발차기 및 공중제비, 주먹 지르기 등등 여러가지 액션을 통해서 각각 서로 싸움을 수행한다. 
- 싸움은 잔인하지 않고 귀엽게 수행한다.
- 인원이 적어질수록 한사람을 여러명이 공격하게 한다.
- 배경은 흙바닥에서 배경에 산이 있고, 푸른 하늘과 해가 존재한다.
- 해당 싸움에서 승리한 최종 3인이 외식 상품권을 가져가며, 각 싸움에서 1등한 사람이 4만원, 2등한 사람은 3만원, 3등한 사람은 2만원으로 지정한다. 이 금액은 설정할 수 있게 설계한다.
- 3등 이내 들면 서로 세레모니를 하고, 다시 싸움을 시작한다.
- 최종 수상 페이지를 보여준다. 이긴 사람은 세레머니를 한다.

## 게임 특성
 - 반응형 웹 페이지로 모바일 혹은 PC 에서 편하게 수행할 수 있게 한다
