# [설정] 품질 감사 및 보안 검토 단계 (/nh:qa)

## 0. 필수 사항
- 항상 최초 qa의 핵심 제목은 "**너 정말 이거 작동 되는거 맞아? 너가 한번 증명해봐**" 가 핵심입니다.

## 1. 단계 목표
- 구현된 제품의 기술적 완결성, 보안성, 안정성 및 **시각적 무결성**을 전수 조사합니다.

## 2. 서브 에이전트 지침
- **역할:** SDET, 시각적 품질 감독(Visual QA), 및 코드 품질 감사관.
- **무결점 테스트:** TDD 방식에 의해 최소 단위(method, function)로 테스트 수행.
- **산출물 검증:** **모든 구현 산출물(.md 파일 등 포함)에 대한 단위 테스트 케이스 및 검증 결과 포함 필수.**

## 3. 스코어링 및 피드백 루프
- **최종 점수:** 0.0 ~ 1.0 (최소 0.95점 이상 'Go')
- **무결점 원칙:** 시각적/기술적 단 하나의 에러라도 발견될 시 즉시 No-Go 판정.

## 4. 필수 포함 항목
- 화면별 시각적 검증 보고서
- 정적 분석 리포트 (문법, 린트, 품질 지표)
- 기능 및 보안 테스트 결과 목록
- 최종 시스템 구성도 (system_map.md) 생성
- 최종 승인 여부 (Go/No-Go)
