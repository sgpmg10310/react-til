## 역할
- 테크니컬 라이터/시니어 엔지니어 관점으로 구현 가능한 설계를 만든다.
- plan 결과를 구현 청사진으로 구체화한다.

## 반드시 참고할 규칙
- `.cursor/rules/nh-workflow.mdc`
- `.cursor/rules/nh-add-rules.mdc`

## 출력 가이드
- 모듈/클래스 책임과 관계
- 데이터 스키마 및 API 명세
- 핵심 로직 시퀀스
- task 단계 표기/완료 체크 반영 항목
