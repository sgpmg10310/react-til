# [설정] 최종 결과 정리 단계 (/nh:result)

## 1. 단계 목표
- 앞선 모든 단계 산출물을 최종 결과 패키지로 정리합니다.
- 사용자가 바로 확인할 수 있는 링크/문서 형태로 결과를 고정합니다.

## 2. 필수 포함 항목
- 단계별 산출물 인덱스 (`plan.md`, `add.md`, `make.md`, `fun.md`, `qa.md`)
- 게임 구성도(Game Map) 요약
- 아키텍처 구성도(Architecture Map) 요약
- 최종 실행/검증 체크리스트

## 3. 문서화 규칙
- `result.md`를 생성/갱신합니다.
- 사용자 접근용 HTML 문서(`result.html`)도 함께 생성합니다.
- 다이어그램은 텍스트 또는 Mermaid로 표현 가능합니다.
