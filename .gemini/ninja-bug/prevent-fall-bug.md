# Ninja Game Bug Prevention: "The Left Abyss"

## 1. 현상
- 게임 시작 직후 플레이어가 왼쪽(`x < 0`)으로 이동하거나 플랫폼 끝에서 떨어질 경우, 세계 경계 밖으로 나가며 캐릭터가 사라지는 현상.

## 2. 방지 규칙 (Mandatory)
- **세계 경계 충돌 활성화:** 플레이어 객체 생성 시 반드시 `player.setCollideWorldBounds(true)`를 설정하여 왼쪽 벽 밖으로 나가는 것을 물리적으로 차단해야 함.
- **낙사(Fall to Death) 체크:** `update` 루프에서 플레이어의 Y 좌표가 세계 높이(`600`)를 초과하는지 상시 체크하고, 초과 시 즉시 `handleDamage` 또는 사망 시퀀스를 호출해야 함.
- **플랫폼 배치 전략:** 첫 번째 플랫폼의 시작 지점은 플레이어의 스폰 지점을 충분히 커버할 수 있도록 `x: 0`부터 시작하거나 안전 거리를 확보해야 함.

## 3. 검증 방법
- 게임 시작 시 왼쪽 키를 계속 눌러도 화면 밖으로 나가지 않는지 확인.
- 의도적으로 낭떠러지로 떨어졌을 때 캐릭터가 사라지지 않고 정상적으로 '사망 연출(머리띠 드롭)'이 발생하는지 확인.
